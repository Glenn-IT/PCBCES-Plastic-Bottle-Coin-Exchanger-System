Breadboard Wiring Table
Component Pin Wire Color Connects To Function
LCD VCC Red 5V Power Rail Display Logic Power
LCD GND Black Common GND Rail Ground Reference
LCD SDA Green Arduino A4 I2C Serial Data
LCD SCL Yellow / Blue Arduino A5 I2C Serial Clock
Button Green (1.5L) Green Wire Arduino D10 Selects 1.5L / 1.75L Mode (5 pcs quota = ₱20.00, INPUT_PULLUP to GND)
Button Blue (Mismo / 290 ML) Blue Wire Arduino A0 Selects 290 ML Mode (10 pcs quota = ₱3.00, INPUT_PULLUP to GND)
Button Red (Restart) Red Wire Arduino A1 Cancels current transaction, resets count & returns to start
All Buttons Common Black Wire Common GND Rail Common Ground Return for all 3 buttons
Buzzer (+) Orange Arduino D12 Active High 5V Beep Output
Buzzer (-) Black Common GND Rail Ground Return
💡
3-Button Operation & Testing Tips
  • LCD Standby Screen: Displays GRN:1.5L BLU:290 on Line 1, and RED:Cancel/Reset on Line 2.
  • GREEN Button (D10): Instantly selects 1.5L / 1.75L Mode (Quota: 5 bottles = ₱20).
  • BLUE Button (A0): Instantly selects 290 ML Mode (Quota: 10 bottles = ₱3).
  • RED Button (A1): Press at ANY time to abort/cancel transaction, reset count to 0, and return to Standby.
  • Serial Monitor: Open Arduino Serial Monitor at 115200 baud to view real-time state outputs.
